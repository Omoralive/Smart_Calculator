# Smart Calculator

A browser-based calculator built with HTML, CSS and vanilla JavaScript.

## Features
- Basic operations: addition, subtraction, multiplication and division
- Operator shown on the display while typing
- Clear (AC) button to reset
- Division by zero handled with an error message

## Built With
- HTML
- CSS
- JavaScript (no libraries, no `eval`)

## What I Learned
- Handling click events with `addEventListener`
- Reading input values and converting strings to numbers
- Keeping state between clicks using variables outside the handler
- Using `if / else if` logic and early `return`

## How to Run
Download or clone the repo and open `index.html` in your browser.
